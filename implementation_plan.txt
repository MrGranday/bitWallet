# Bitcoin Network Integration Implementation Plan (Archived)

Note: This plan has been successfully EXECUTED.

## Goal
Integrate real on-chain Bitcoin capabilities into bitWallet, allowing users to deposit real BTC (on Testnet) to their accounts, and withdraw real BTC.

## Architecture Logic (Hot Wallet)
1. The Platform Hot Wallet: The application runs a single `bdk` Wallet (the Hot Wallet).
2. User Deposits: When a user wants to deposit, the Hot Wallet generates a new, unique receiving address. We tie this address to the user in the MongoDB database. 
3. Listening to the Blockchain: The application periodically calls `wallet.sync()` against an Esplora node. Any new unspent transaction outputs (UTXOs) arriving at a user's address triggers a credit to their internal balance.
4. User Withdrawals: When a user requests to withdraw, the application checks their internal balance. If sufficient, the Hot Wallet creates, signs, and broadcasts a real Bitcoin transaction to the user's external destination address.

## Executed Changes

### 1. bitwallet_chain/Cargo.toml
- Updated versions of `bdk` (0.30.2) and `bdk_esplora` (0.22.1).
- Configured BDK to use feature flags: `default-features = false, features = ["compiler", "use-esplora-reqwest"]`.

### 2. bitwallet_chain/src/lib.rs
- `init_hot_wallet()`: Initializes a BDK Wallet using a descriptor loaded from `.env`.
- `generate_deposit_address()`: Calls BDK to map a new Testnet address index.
- `sync_wallet()`: Syncs with Esplora using `SyncOptions::default()`.
- `withdraw_on_chain()`: Uses `TxBuilder` to construct a transaction sending to an external address with a 5 sat/vB fee rate, then signs and broadcasts via Esplora.

### 3. src/db.rs
- Updated `WalletUser` struct to optionally store `deposit_address`.
- Implemented `assign_deposit_address(email, address)` to save generated addresses.
- Implemented `credit_onchain_deposit(email, sats, txid)` to map on-chain UTXOs verified by Esplora tightly to the user's internal `balance`.

### 4. src/main.rs
- Removed old mock sequential logic.
- Bootstrapped BDK hot wallet initialization.
- Added demo flow: generating address for a user -> syncing from Esplora -> printing balances -> (optional) executing an external withdrawal.
